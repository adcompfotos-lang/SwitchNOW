# SwitchNOW 1.1.6

Версия 1.1.6 добавляет полноценный клиентский путь обязательной рекламы NVIDIA
для бесплатного тарифа GeForce NOW и исправляет сбой быстрого входа на части
консолей.

## Реклама Free-tier

- Разбираются реальные поля `sessionAdsRequired`, `sessionAds`, `adProvider`,
  длительность ролика и доступные MP4, HLS и WebM-источники.
- Рекламная пауза отделена от обычной очереди и показывается на собственном
  экране с видео, звуком, индикатором прогресса и оставшимся временем.
- Добавлен изолированный FFmpeg-проигрыватель. Он не запускает игровой WebRTC
  и освобождает аудио, декодер, GPU-кадры и временный файл после просмотра.
- Начало, завершение и отмена передаются CloudMatch официальным действием
  обновления рекламы. `Finish` отправляется только после фактического EOF
  воспроизводимого ролика, а не по локальному таймеру.
- После подтверждённого просмотра продолжается тот же `PollSession`, без
  создания второй облачной сессии.
- Если ответ на начало просмотра содержит следующий рекламный ролик, список
  обновляется с сервера и вся рекламная пауза воспроизводится последовательно.
- Формат отчётов `Start`, `Finish` и `Cancel` синхронизирован с desktop OpenNOW.
  Просмотренное время успешного ролика нормализуется до объявленной длительности,
  чтобы погрешность таймера не отклонялась CloudMatch как неверный запрос.
- Отмена запуска, ошибка загрузки и обрыв воспроизведения не маскируются под
  успешный просмотр.
- Пропуск не показывается, потому что исследованный ответ NVIDIA не содержит
  разрешённого действия или времени пропуска. Ложное подтверждение просмотра
  не используется.
- Сессии, где NVIDIA не требует рекламу, продолжают идти по прежней ветке:
  медиаплеер не запускается и рекламные запросы не отправляются.

## Авторизация

- Исправлен сбой после успешного ввода пароля на старом TLS-бэкенде libnx.
  Authorize, обмен OAuth-кода, `client_token` и профиль теперь используют одно
  проверенное соединение вместо отдельного проблемного POST-сеанса.
- Обновление сохранённого входа использует тот же долгоживущий транспорт с
  безопасным preflight, поэтому исправление охватывает и первичный вход, и автологин.
- Проверка сертификата и имени хоста остаётся полной. Отключение SSL-проверки и
  пользовательский CA-набор не используются.
- `runtime.log` содержит endpoint без query, HTTP/curl-код, IP и длительность,
  но не записывает пароль, OAuth-код или токены.

## Диагностика и устойчивость

- Добавлена безопасная диагностика рекламного состояния без записи полного
  URL и идентификатора рекламы в краткие события.
- Буферизованные кадры FFmpeg выводятся перед завершением ролика.
- Начало просмотра подтверждается только после первого декодированного
  видеокадра. Аудиопоток без изображения больше не считается успешным роликом.
- В журнал добавлены кодеки, параметры медиапотоков, число видео- и аудиокадров,
  ошибки декодирования и итоговая причина завершения без подписанных URL.
- Аудиобуферы рекламного проигрывателя синхронизируются с кэшем CPU перед
  передачей аудиоустройству Nintendo Switch.
- Для медиа без корректных PTS используется ограниченный резервный тайминг,
  чтобы ролик не завершался мгновенно и не отправлял неверный прогресс.
- Зависшее сетевое чтение прерывается при отмене, а временный файл удаляется
  как после успеха, так и после ошибки.

## Проверка на устройстве

Сборка и host-side тесты проходят локально. Финальную совместимость конкретной
рекламной выдачи NVIDIA и исправления TLS необходимо подтвердить одним запуском
на Nintendo Switch с Free-tier аккаунтом.
