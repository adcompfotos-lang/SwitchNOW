# SwitchNOW 1.2.0

SwitchNOW 1.2.0 объединяет проверенную стабильную основу 1.1.7 и исправления,
которые проходили отдельное тестирование в сборках r2-r10.

## Основные изменения

- Улучшены автоматическое измерение задержки и выбор ближайшего сервера GeForce NOW.
- Добавлено корректное распознавание Free, Performance/Priority и Ultimate с цветовой индикацией и сведениями о доступных ресурсах подписки.
- Доработана поддержка обязательной рекламы NVIDIA для Free tier и переход к исходной игровой сессии после рекламного блока.
- Добавлено создание персональных HOME-ярлыков игр с иконкой и универсальным поиском установленного SwitchNOW независимо от имени и версии NRO.
- Добавлена ручная проверка обновлений через официальный GitHub-репозиторий с проверкой SHA-256 и безопасным helper-установщиком.
- Исправлены размеры и навигация интерфейса в docked mode.
- Переработан поиск по библиотеке и магазину, добавлен быстрый выход кнопкой B.
- Дополнены переводы интерфейса, поиска, этапов запуска сессии, рекламы и обновлений для всех поддерживаемых языков.
- Устранены гонки фокуса и жизненного цикла Borealis после сохранения настроек и создания HOME-ярлыка.
- Исправлено окно результата создания ярлыка: фокус сразу находится на кнопке закрытия, а основной интерфейс создаётся только после полного завершения предыдущего Activity.
- Сохранены стабильные видеопуть, ввод, звук, долгоживущая NVIDIA-авторизация и запуск сессий без рекламы из версии 1.1.7.

## Установка

1. Распакуйте архив в корень SD-карты с сохранением папки `switch/SwitchNOW`.
2. Запускайте SwitchNOW через Homebrew Menu в Application mode/title override.
3. При обновлении замените `switch/SwitchNOW/SwitchNOW.nro`; настройки и сохранённые аккаунты останутся на месте.

## Важно

- SwitchNOW является неофициальным homebrew-клиентом и не связан с NVIDIA.
- HOME-ярлыки требуют Application mode для создания.
- Если системный TLS Nintendo Switch перестал работать после частого переключения приложений, полностью перезагрузите консоль.
