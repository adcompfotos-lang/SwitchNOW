# SwitchNOW 1.1.7

Версия 1.1.7 открывает новую стабильную ветку разработки на основе проверенной
сборки 1.1.6 test-r6.

## Основные изменения

- Удалены не подтвердившие эффективность экспериментальные изменения TLS.
- Восстановлен стандартный сетевой стек Nintendo Switch/devkitPro.
- Удалены ограничения параллельных TLS-соединений и фоновых загрузок.
- Сохранена долгоживущая авторизация NVIDIA через `client_token`.
- Сохранена поддержка обязательной рекламы NVIDIA для Free tier.
- Сохранён стабильный путь запуска сессий без рекламы.

## Важно

Если после частого переключения приложений Provider Discovery начинает выдавать
ошибку проверки сертификата, сначала полностью перезагрузите Nintendo Switch.
SwitchNOW больше не пытается изменять системное TLS-состояние или обходить штатную
проверку сертификатов.
