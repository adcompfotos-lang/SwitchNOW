# SwitchNOW 1.x: накопительный черновик патчноута

Этот файл хранит изменения, сделанные после выпуска SwitchNOW 1.0.0.
Он предназначен для подготовки большого патчноута и описания будущего
GitHub Release. Перед публикацией текст можно сократить и перевести на
английский язык.

## 1.0.0

Первый публичный релиз SwitchNOW.

Основные возможности базовой версии:

- нативное homebrew-приложение Nintendo Switch в формате `.nro`;
- интерфейс на Borealis, оптимизированный для управления геймпадом;
- авторизация GeForce NOW и сохранение нескольких аккаунтов;
- автоматическое обновление краткоживущих токенов авторизации;
- каталог и библиотека игр с обложками;
- выбор магазина перед запуском игры;
- создание и отслеживание облачной игровой сессии;
- программный и экспериментальный аппаратный видеодекодер;
- вывод звука и регулируемое усиление громкости;
- эмуляция Xbox-контроллера и альтернативная Switch-раскладка ABXY;
- сенсорное управление курсором;
- экранная клавиатура;
- настройки потока, языка игры, звука, управления и диагностики;
- локализация интерфейса на несколько языков;
- диагностические журналы для авторизации, сессии, стриминга, звука,
  управления и интерфейса.

## 1.0.1 Test

### Исправлена ошибка запуска облачной сессии

Исправляется ошибка NVIDIA CloudMatch:

```text
HTTP 403
statusCode=50
SESSION_LIMIT_PER_DEVICE_EXCEEDED_STATUS
```

Ошибка означала, что сервер NVIDIA считал, что для устройства уже существует
активная или зависшая облачная сессия.

### Устранена основная причина

В SwitchNOW использовался одинаковый тестовый идентификатор устройства:

```text
12345678-1234-5678-1234-567812345678
```

Из-за этого разные установки SwitchNOW могли выглядеть для NVIDIA как одно
устройство. Незавершённая сессия одной установки могла блокировать запуск
новой сессии.

В 1.0.1:

- удалён общий жёстко заданный ID;
- используется постоянный уникальный ID конкретной установки SwitchNOW;
- ID создаётся один раз и сохраняется на SD-карте;
- существующий локальный секрет устройства преобразуется в стабильный UUID;
- повторные запуски приложения используют тот же ID;
- формат ID соответствует формату, используемому официальным desktop-клиентом.

Существующий файл идентичности не перезаписывается. Это сохраняет совместимость
с локальным хранилищем токенов SwitchNOW.

### Добавлено управление зависшими серверными сессиями

Перед созданием новой игровой сессии SwitchNOW теперь:

1. Обновляет токен авторизации, если это необходимо.
2. Запрашивает у NVIDIA список активных CloudMatch-сессий через
   `GET /v2/session`.
3. Рассматривает состояния `Setup`, `Ready` и `Streaming` как активные.
4. Ищет сессию текущего устройства или сессию, ранее записанную самим
   SwitchNOW.
5. Отправляет запрос завершения найденной сессии.
6. По возможности обращается непосредственно к серверу, обслуживающему
   сессию, а не только к балансировщику региона.
7. Только после очистки создаёт новую сессию.

Сессии других устройств намеренно не завершаются автоматически.

### Добавлен безопасный повтор запуска

Если первый запрос запуска всё ещё возвращает
`SESSION_LIMIT_PER_DEVICE_EXCEEDED_STATUS`, SwitchNOW:

- повторно обновляет список серверных сессий;
- ещё раз выполняет безопасную очистку подходящей сессии;
- обновляет авторизацию;
- повторяет создание сессии ровно один раз.

Количество повторов ограничено, чтобы избежать бесконечного цикла запросов.

Если NVIDIA ещё освобождает предыдущую облачную машину, пользователь получает
понятное сообщение с предложением подождать около минуты и повторить запуск.

### Улучшена диагностика CloudMatch

В `session_trace.log` теперь сохраняются:

- постоянный ID устройства, использованный при запуске;
- URL запроса списка сессий;
- HTTP-статус и ответ сервера;
- найденные активные сессии и их состояния;
- источник решения об очистке: локальная запись или совпадающее устройство;
- адрес сервера, которому отправлен запрос завершения;
- результат завершения зависшей сессии;
- обнаружение лимита сессий;
- результат единственного повторного запуска.

Это должно позволить диагностировать повторную ошибку за один тест без
дополнительных специальных сборок.

### Авторизация и удержание входа

Ошибка `SESSION_LIMIT_PER_DEVICE_EXCEEDED_STATUS` не была связана с истечением
авторизации.

SwitchNOW уже хранит долгоживущие данные входа и обновляет краткоживущий токен:

- перед запросами GeForce NOW;
- при приближении срока истечения;
- после ответа HTTP 401;
- при восстановлении сохранённого аккаунта.

OpenNOW использует похожую модель: постоянным является не короткий JWT, а
refresh/client token, через который выпускается новый рабочий токен. Облачная
игровая сессия и сессия авторизации имеют разный жизненный цикл.

## Изменения после 1.0.1: интеграция OpenNOW-Switch 0.0.4

Статус: изменения реализованы и успешно собраны локально. Перед публичным
релизом требуется дополнительная проверка на реальной Nintendo Switch.

### Выбор сервера GeForce NOW

- Добавлена модель регионов потоковых серверов GeForce NOW.
- Реализовано автоматическое измерение задержки до доступных регионов.
- В автоматическом режиме приложение выбирает сервер с наименьшей задержкой.
- Результат измерения кэшируется на 15 минут, чтобы не выполнять лишние
  сетевые запросы при каждом запуске игры.
- В настройки добавлены ручной выбор региона и обновление списка серверов.
- Исправлена согласованность адресов API: создание, проверка состояния и
  завершение сессии теперь используют один выбранный streaming endpoint.
- Сохранение активной сессии также учитывает фактически использованный сервер.
- Добавлен безопасный откат на официальный endpoint NVIDIA, если список
  регионов временно недоступен.

### ICE, соединение и задержка

- Улучшен выбор ICE candidate pair согласно приоритетам кандидатов.
- Пары кандидатов сортируются по рассчитанному приоритету перед проверкой
  соединения.
- Добавлено измерение RTT по STUN.
- Добавлен резервный расчёт RTT через SCTP, если STUN-значение недоступно.
- RTT и состояние выбранной ICE-пары добавлены в диагностические данные
  стриминга.
- Изменения помогают быстрее выбирать рабочий сетевой маршрут и упрощают поиск
  причин микрофризов и нестабильного подключения.

### Видеопоток и производительность

- Добавлена адаптивная глубина очереди декодирования:
  - до 2 кадров для 30 FPS;
  - до 4 кадров для 60 FPS;
  - целевой запас составляет около 67 мс.
- Ограничение очереди уменьшает накопление задержки без слишком агрессивного
  удаления кадров.
- Сохранена пакетная обработка до 24 UDP-датаграмм за один проход сетевого
  цикла.
- Добавлена адаптивная пауза сетевого потока:
  - 1 мс при готовом соединении без новых пакетов;
  - 2 мс, пока соединение ещё не готово.
- Уменьшена лишняя нагрузка на CPU во время простоя без ухудшения реакции на
  новые медиапакеты.

### Сборка и переносимость

- Исправлено подключение зависимостей Borealis/GLFW в CMake.
- Локально собранные библиотеки имеют приоритет над несовместимыми системными
  вариантами.
- Скрипт `build-switch.ps1` поддерживает оба распространённых расположения
  MSYS2/devkitPro.
- Настройка mbedTLS для libpeer сделана повторяемой и безопасной при нескольких
  сборках подряд.
- Удалены дублирующиеся блоки конфигурации mbedTLS.
- Статические библиотеки подключаются по однозначным абсолютным путям, что
  уменьшает вероятность использования неправильной версии зависимости.

### Проведённые проверки

- Добавлены тесты политики выбора сервера.
- Добавлены тесты расчёта приоритета ICE candidate pair.
- Добавлены тесты глубины очереди декодирования для 30 и 60 FPS.
- Добавлены тесты адаптивной паузы сетевого цикла.
- Изменённые C++-модули успешно проверены компилятором devkitA64.
- Полная Release-сборка для Nintendo Switch завершена успешно.

### Намеренно не перенесено

- Community proxy не добавлялся: он меняет модель доверия и требует отдельного
  решения по приватности и отказоустойчивости.
- QR-only авторизация не заменяет существующую систему входа SwitchNOW.
- Перехват кнопки HOME и отдельный HOME-forwarder не добавлялись из-за
  системных рисков и возможных конфликтов с Atmosphere.
- Аудиобуфер из форка не перенесён без аппаратного A/B-теста, чтобы не вернуть
  шипение и нестабильность в начале сессии.
- Полная замена текущей архитектуры модульной структурой форка не выполнялась:
  переносились только изолированные улучшения с понятным эффектом.

### Что ещё осталось перенести или адаптировать

Обязательных критических исправлений из OpenNOW-Switch 0.0.4 после текущего
этапа не осталось. Следующие изменения являются кандидатами для дальнейшей
адаптации:

1. **Локализация выбора сервера.** Добавить переводы новых названий, описаний,
   состояний измерения задержки и сообщений об ошибках региона на все языки,
   поддерживаемые SwitchNOW.
2. **RTT в компактном оверлее.** Вывести текущую сетевую задержку рядом с FPS и
   другими краткими показателями производительности, не требуя включения
   полного диагностического экрана.
3. **Аудиоподготовка перед воспроизведением.** Сравнить стартовый аудиобуфер
   форка с действующей системой защиты SwitchNOW от шипения. Переносить эту
   логику можно только после A/B-теста на консоли, если она не увеличивает
   задержку и не возвращает шум в начале сессии.
4. **Расширенная диагностика ICE-пар.** Добавить подробный журнал всех
   проверенных candidate pair, их приоритетов и причин отказа только в
   диагностическом режиме. Это потребуется, если аппаратные тесты обнаружат
   неправильный выбор маршрута.
5. **Разделение крупных модулей.** Постепенно разделить монолитные реализации
   GeForce NOW и WebRTC на меньшие компоненты после стабилизации поведения.
   Это архитектурное улучшение, а не обязательная функция текущего релиза.

Следующие части форка не входят в план переноса без отдельного решения:

- community proxy и перенаправление трафика через сторонний сервер;
- замена текущей авторизации на QR-only flow;
- установка HOME-forwarder и перехват системной кнопки HOME;
- полная замена существующих модулей сессии, WebRTC, управления или аудио
  вариантами форка.

### Что ещё требуется проверить

- Сравнить автоматический и ручной выбор региона на реальной консоли.
- Проверить RTT и скорость установления ICE-соединения на разных сетях.

- Проверить корректное завершение активной сессии при потере сети и повторном

## 1.0.2 Test

### Экранная клавиатура и Escape

- Во время работы экранной клавиатуры кнопка `X` теперь отправляет в удалённую
  игру полноценное нажатие `Esc`, не закрывая клавиатуру и не разблокируя
  игровой ввод.
- Физическая клавиша `Esc` подключённой USB-клавиатуры также пересылается в
  удалённую игру до того, как системная клавиатура Switch обработает её как
  отмену.
- В правом верхнем углу клавиатуры отображается компактная подсказка:
  `X Esc`, `+ Enter`, `B Close`.
- Сохранено прежнее безопасное поведение: `B` закрывает клавиатуру без ввода,
  а `+` подтверждает ввод клавишей Enter и закрывает её.
- Реализация не заменяет системную `SwkbdInline`, поэтому сенсорный ввод,
  навигация геймпадом и существующие раскладки продолжают работать.

### Страница игры и изображения

- Клиент больше не отбрасывает `GAME_BOX_ART`, `HERO_IMAGE` и `TV_BANNER`,
  возвращаемые официальным каталогом NVIDIA.
- Плитка библиотеки запрашивает обложку повышенного разрешения, а страница игры
  использует отдельные изображения для вертикального постера и широкого
  баннера.
- На странице игры добавлена компактная галерея доступных NVIDIA-изображений.
- Добавлены полное описание, издатель, магазины, уровень подписки и дата
  последнего запуска, если эти данные присутствуют в ответе GeForce NOW.
- Изображения разных размеров получают разные ключи кеша, поэтому ранее
  сохранённая низкокачественная плитка не подменяет постер или широкий баннер.

### Исправление вылета настроек

- Устранено уничтожение сфокусированной строки непосредственно внутри
  обработчика `X Save`. Именно эта последовательность оставляла Borealis
  устаревший указатель фокуса после изменения раскладки управления.
- Обычное сохранение теперь обновляет значения на существующих элементах без
  перестройки экрана.
- Полная перестройка нужна только после смены языка и выполняется отложенно с
  последующим переводом фокуса на стабильную кнопку категории.

### Универсальный журнал запуска

- Добавлен всегда включённый
  `sdmc:/switch/SwitchNOW/runtime.log` для запуска приложения, автологина,
  редких UI-действий и HTTP/TLS-запросов до начала стриминга.
- Для сетевых ошибок сохраняются код curl, результат проверки сертификата,
  текст TLS-бэкенда, полученный IP-адрес и длительность запроса.
- Токены, параметры URL, фрагменты, данные пользователя и содержимое
  логина/пароля в журнал не записываются.
- Успешные запросы обложек не журналируются, поэтому новая диагностика не
  создаёт постоянную нагрузку при прокрутке библиотеки.
- Успешные циклические проверки очереди также не записываются; при сетевой
  ошибке такой проверки в журнал попадает один диагностический результат.
- Размер файла ограничен 512 КиБ; предыдущая копия сохраняется как
  `runtime.log.previous`.
- Состояние `runtime.log` добавлено в экран Diagnostics. Полные потоковые логи
  по-прежнему создаются только при включённом диагностическом режиме.

## 1.0.6

### Полностью изолированная область описания

- Стандартная навигация `ScrollingFrame` заменена отдельной политикой
  прокрутки описания, которая не передаёт фокус кнопкам во время движения
  по тексту.
- Описание теперь свободно прокручивается вниз и вверх. Достижение верхней
  границы не выбрасывает пользователя из области: переход к кнопкам
  выполняется только следующим нажатием вверх при смещении `0`.
- Короткое нажатие `B` сразу возвращает фокус к последней смысловой кнопке
  страницы игры, не закрывая сам экран игры.
- Добавлено удержание направлений с повтором, поэтому длинные описания можно
  быстро и предсказуемо читать в обе стороны.

### Исправление пустых областей

- У многострочной метки снято стандартное ограничение Borealis
  `max-height: 100%`, которое обрезало реальную высоту текста и ломало
  диапазон прокрутки.
- Удалено принудительное растягивание контейнера описания. Короткие описания
  Doom (2016), Don't Starve Together и других игр больше не создают пустую
  область без полосы прокрутки.
- Высота области рассчитывается по фактическим границам локализованного
  многострочного текста и ограничивается только доступным местом страницы.
  Расчёт автоматически учитывает две или три кнопки игры.

### Проверки

- Добавлен независимый тест политики прокрутки: границы, свободное движение
  в обе стороны, сохранение фокуса при возврате к началу и выход только
  отдельным нажатием вверх.
- Nintendo Switch `.nro` успешно собран после замены компонента описания.

## 1.0.5

### Навигация по описанию

- Корневой контейнер текста добавлен в цепочку фокуса `ScrollingFrame`.
- При нажатии вверх фокус остаётся внутри описания, пока прокрутка не вернётся
  к самому началу. Переход к кнопкам выполняется только со смещения `0`.
- Визуальная рамка большого контейнера скрыта, поэтому исправление навигации
  не меняет оформление страницы игры.

### Escape на ZL

- Горячая клавиша удалённого `Esc` перенесена с `L3` на `ZL`.
- `L3` снова полностью принадлежит системной экранной клавиатуре и может
  использоваться для регистра и её штатных функций.
- Подсказка поверх потока обновлена на `ZL ESC`. Надёжная 85-миллисекундная
  пара key-down/key-up и освобождение зависшей клавиши сохранены.

### Быстрая и стабильная галерея

- Последовательная очередь Borealis заменена выделенным загрузчиком из трёх
  рабочих потоков с приоритетами: текущий скриншот, видимые обложки и фоновая
  предзагрузка.
- Одинаковые одновременные запросы объединяются: данные скачиваются один раз,
  после чего результат получают все ожидающие элементы интерфейса.
- Добавлен процессный LRU-кеш до 16 МиБ для сжатых изображений поверх
  существующего кеша на SD-карте.
- Предыдущий и следующий скриншоты загружаются заранее. При перелистывании
  текущая картинка остаётся на экране до готовности новой.
- Добавлен счётчик поколения галереи: завершившийся с опозданием запрос больше
  не может заменить скриншот, который пользователь выбрал позже.
- Активные скриншоты запрашиваются шириной 1120 вместо 1280 пикселей. Снижение
  составляет 12,5% и уменьшает сетевой трафик и время декодирования без
  заметной потери качества на области галереи.
- Миниатюры плиток и экрана запуска запрашиваются шириной 420 вместо 544
  пикселей. Это на 22,8% меньше исходного варианта и всё ещё даёт почти
  двукратный запас относительно физического размера плитки.
- Таймаут изображений сокращён до 15 секунд, а подключение до 5 секунд, чтобы
  зависший CDN-запрос не блокировал очередь надолго.
- Перед использованием и кешированием проверяется сигнатура JPEG, PNG, GIF
  или WebP. Повреждённый файл удаляется и запрашивается повторно.
- Размер файла кеша проверяется до его чтения в память; аномальный файл больше
  не может вызвать резкий расход памяти или зависание галереи.
- Запись кеша стала атомарной через временный файл, поэтому прерванное
  скачивание или выключение консоли не оставляет частичное изображение.

### Проверки

- Добавлен host-side тест преобразования NVIDIA image URL, включая сохранение
  дополнительных параметров изображения.
- Полная Switch Release-сборка с новым многопоточным загрузчиком выполнена
  успешно.

### Локализация

- Дополнены китайский, испанский, русский, итальянский, французский, польский и
  украинский словари для страницы игры, каталога, библиотеки, очереди, настроек

- Динамические строки с количеством игр, номером страницы и позицией в очереди

- Удалённое нажатие отправляется как удерживаемая 85 мс пара key-down/key-up.

- Экранная подсказка теперь явно показывает `L3 ESC`; обычное закрытие
  клавиатуры продолжает работать штатно и больше не конкурирует с Escape.

### Карточка игры и метаданные NVIDIA

- Библиотека дополнительно обогащается через официальный persisted-запрос
  NVIDIA `appMetaData` пакетами до 40 игр. Основная библиотека продолжает

  `KEY_ART` больше не выдаются за игровые кадры. Карусель использует только

- Под главным скриншотом добавлены центрированные точки по реальному числу

- Для изображений страницы игры запрашивается вариант шириной до 1280 пикселей.

### Экранная клавиатура и Escape

- Комбинация `Minus + Y` получила отдельное состояние готовности и защиту от
  повторного срабатывания, поэтому после закрытия или длительного простоя она
  снова корректно открывает клавиатуру.
- Перед каждым новым открытием создаётся свежий экземпляр `SwkbdInline`, что
  устраняет накопление устаревшего состояния системного applet.
- После трёх последовательных ошибок обновления клавиатура автоматически
  освобождается и может быть вызвана повторно без перезапуска стрима.
- В 1.0.3 экспериментальная кнопка `X ESC` отправляла scancode Escape, но
  системная клавиатура могла перехватывать `X`. В 1.0.4 этот конфликт устранён
  переносом Escape на `L3`.

### Всегда включённый runtime-журнал

- `sdmc:/switch/SwitchNOW/runtime.log` продолжает записываться независимо от
  настройки расширенной диагностики.
- В журнал добавлен явный маркер режима диагностики, этап обогащения библиотеки

  лишнюю нагрузку во время игры.
