# SwitchNOW 1.1.3 Hotfix

Версия 1.1.3 представляет собой небольшой сетевой хотфикс для более точной диагностики задержки во время облачной трансляции. Обновление не меняет привычную логику интерфейса и сосредоточено на измерении реального состояния соединения.

## Что исправлено

- Добавлено периодическое измерение RTT через STUN в течение всей трансляции.
- Между STUN-замерами используется RTT транспортного канала SCTP.
- Потерянные, просроченные и несопоставленные STUN-ответы больше не искажают статистику.
- Показатель задержки обновляется примерно раз в секунду без нагрузки на видеопоток.
- В диагностику добавлены текущий, минимальный и P95 RTT, а также джиттер.
- Расчёт P95 выполняется только при поступлении нового корректного измерения и не затрагивает горячий путь рендера.
- Ограничены повторные попытки после мгновенной ошибки отправки STUN-запроса.

## Новая диагностика

При включённом диагностическом режиме оверлей и `signaling.log` показывают:

- текущий RTT;
- минимальный RTT;
- P95 RTT;
- джиттер;
- источник текущего измерения: STUN или SCTP;
- состояние и результаты фоновых STUN-проб.

## Установка

Скопируйте `SwitchNOW.nro` в папку:

`/switch/SwitchNOW/`

Затем запустите приложение через Homebrew Menu в режиме полной памяти.
